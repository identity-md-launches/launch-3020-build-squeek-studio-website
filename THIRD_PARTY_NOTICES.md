# Third-party notices

The original interface, artwork decorations, and studio code are made for this assignment. The Squeek character artwork and metadata are read from the collection specified in the README; no Squeekchain logo is included. This is an unofficial fan project.

Design guidance was adapted from Jakub Krehel's **Better Interface**, commit `267330e1adfc66a718fb65fa6918c1f06d0a689e` (MIT), and the documentation method from Paul Bakaus's **Impeccable**, commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8` (Apache-2.0). The pinned combined license texts are retained in `licenses/interface-guides.txt`. Sources: https://github.com/jakubkrehel/skills and https://github.com/pbakaus/impeccable/blob/9d715cc4f5564a990ca8345abfdd5df6dc9b41c8/skill/reference/document.md.

Bundled runtime dependencies include React, React DOM, viem, qrcode, and fflate. Their license notices, together with notices for installed transitive packages, are retained in `licenses/dependencies.txt`. Vite, TypeScript, tsx, and Playwright are development tools; package versions are pinned in the manifest and lockfile. There are no external fonts or image services.
